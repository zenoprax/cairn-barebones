# About This Fork

This site is a personal, player-focused fork of [Cairn](https://github.com/yochaigal/cairn) by Yochai Gal.
It presents only the **Barebones** rules for quick reference at the table along with the Character Creator and the Dice Roller.
I have excluded the First and Second edition of the rules, the Warden Guide, monster stat blocks, and all other non-essential resources.

By removing everything else it makes it much easier to browse and search without accidentally opening or linking information that is beyond the scope of the Barebones rules.

- This fork's repository: <https://github.com/zenoprax/cairn-barebones>
- Upstream repository: <https://github.com/yochaigal/cairn>
